# EcoRide - Electric Vehicle Rental Mobile App

## 📱 Project Overview

EcoRide is a comprehensive UI/UX design case study for a mobile 
app that helps users discover and rent electric vehicles with 
real-time availability, transparent pricing, and instant booking.

## 🎯 Problem Statement

Users struggle to find reliable, eco-friendly transport options 
with transparent pricing and smooth booking experience. Current 
solutions lack:
- Clear vehicle information
- Real-time availability
- Upfront pricing
- Seamless booking process

## ✨ Solution

EcoRide provides a seamless mobile app with:
- **Location-based EV discovery** - Browse nearby cars on interactive map
- **Transparent pricing** - Zero hidden charges, clear breakdown
- **3-step booking** - Quick, frictionless rental process
- **Live GPS tracking** - Real-time trip monitoring
- **Environmental tracking** - CO₂ savings per trip

## 🎨 Design System

- **Primary Color:** #2ECC71 (Eco-green)
- **Accent Color:** #EAF3DE (Light green)
- **Typography:** Poppins (all weights)
- **Card Radius:** 12px
- **Layout:** Grid-based, spacious design
- **Components:** 10 screens, 30+ UI components

## 📲 10 Mobile Screens

1. **Onboarding** - Welcome & value proposition
2. **Login/Sign Up** - User authentication
3. **Home/Explore** - Browse nearby EVs
4. **Car Details** - Full vehicle information
5. **Search & Filters** - Price, rating, car type filters
6. **Booking** - Select dates & add insurance
7. **Payment** - Secure payment with cost breakdown
8. **Trip Tracking** - Live map & trip details
9. **Trip History** - Past bookings & receipts
10. **User Profile** - Account & stats

## 👥 Target Users

- **Working Professionals (25-40)** - Daily commute solutions
- **Travelers & Tourists (28-45)** - Short-term rentals
- **Eco-Conscious Users (22-50)** - Sustainability advocates

## 🎯 Project Goals

✓ Make EV discovery simple
✓ Provide transparent pricing
✓ Reduce booking friction
✓ Enable real-time trip tracking
✓ Highlight environmental impact
